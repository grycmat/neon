# Changelog — v1.2.0 → next release

Changes since the last version bump (`35e2a6f`, v1.2.0).

## English

- Profile screens now show the account's cover photo tap either the avatar or the cover photo to view it full-screen.
- You can now swipe between photos and videos while viewing them full-screen.
- The compose button now reads "Toot" instead of "Post".

## Polski

- Ekran profilu wyświetla teraz zdjęcie w tle — dotknij awatara lub zdjęcia w tle, aby zobaczyć je na pełnym ekranie.
- Podczas przeglądania zdjęć i filmów na pełnym ekranie możesz teraz przewijać między nimi.
- Przycisk publikowania wpisu wyświetla teraz „Toot" zamiast „Post".
